Política de privacidad de Linterna ShigeT

Última actualización: 6 de noviembre de 2026

Esta política explica cómo funciona el tratamiento de información en la aplicación móvil Linterna ShigeT, desarrollada por AsielaByte.

1. Información que recopilamos

Linterna ShigeT no solicita al usuario que proporcione datos personales y, según las funciones y el código de la aplicación revisados para esta versión, no recopila, almacena ni transmite datos personales a servidores del desarrollador o de terceros.

La aplicación no incorpora funciones de registro de cuentas, publicidad ni herramientas de analítica en esta versión.

2. Permiso de cámara y uso del flash

La aplicación solicita el permiso de Android CAMERA únicamente cuando el usuario intenta encender el LED o flash trasero del dispositivo. Android exige este permiso para controlar la linterna mediante la interfaz del sistema.

La aplicación utiliza las funciones del sistema para activar y desactivar el flash. No utiliza este permiso para tomar fotografías, grabar vídeos, capturar audio ni identificar al usuario. Si el permiso no se concede, la función del LED trasero no estará disponible; las funciones de iluminación de pantalla pueden seguir utilizándose.

3. Almacenamiento y comunicaciones

La versión descrita no implementa cuentas de usuario ni almacenamiento propio de información personal. El manifiesto de Android revisado no declara el permiso de acceso a Internet y la aplicación no contiene, en el código revisado, integraciones de envío de datos a servicios externos.

4. Servicios de terceros

Esta versión no integra servicios de publicidad, analítica, redes sociales ni plataformas de seguimiento del desarrollador. El sistema operativo Android y el dispositivo pueden procesar información técnica conforme a sus propias políticas y configuraciones.

5. Privacidad de menores

La aplicación no está diseñada para recopilar información personal de menores ni de otros usuarios.

6. Seguridad

Al no recopilar ni transmitir datos personales mediante las funciones descritas, la aplicación no mantiene una base de datos propia de información personal. Se recomienda mantener Android actualizado y descargar la aplicación desde fuentes oficiales.

7. Cambios en esta política

Esta política podrá actualizarse si se incorporan nuevas funciones o cambian las prácticas de tratamiento de información. La versión vigente estará disponible en esta misma dirección y mostrará su fecha de actualización.
